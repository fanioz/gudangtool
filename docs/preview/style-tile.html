06

Ikonografi

Grid 24×24, stroke 2px, ujung datar, radius 2px. Maksimal tiga elemen garis per ikon.

07

Batasan

Lakukan

  • Rak, peti, label, lorong sebagai kosakata visual
  • Sudut 2–4px, garis 1px, bayangan keras saat hover
  • Ruang kosong sebagai bagian dari pesan "rapi"
  • Mono hanya untuk label dan metadata
  • Satu warna aksen per layar

Jangan

  • Kunci pas, bor, palu, gerinda, tekstur logam
  • Gradien ungu-biru, blob 3D, mockup dashboard palsu
  • Bentuk pil untuk chip, badge, atau tombol
  • Foto stok orang bekerja di depan laptop
  • Wordmark dimiringkan, outline, atau dijadikan pola
08
